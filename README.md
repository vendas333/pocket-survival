# Pocket Survival

A tiny, mobile-first retro survival game (Phaser 3 + Vite), installable as a PWA on iPhone and Android.

You're lost in a night forest. You fire stones at the nearest monster automatically. Walk into trees and rocks to gather wood and stone, pick berries from bushes to heal, and spend your resources on upgrades. A new wave starts every 30 seconds, and each one is harder than the last.

## Run it locally

Requires Node.js 18+ (tested with Node 24).

```bash
npm install
```

Development server with hot reload (the service worker is disabled in dev):

```bash
npm run dev
```

Open the URL Vite prints (http://localhost:5173). `--host` is on, so a phone on the same Wi-Fi can open the `Network:` URL.

Production build plus local preview (the full PWA with offline support):

```bash
npm run build
```

```bash
npm run preview
```

Then open http://localhost:4173.

Unit tests (difficulty curve, upgrades, high-score storage):

```bash
npm test
```

## Controls

| | Mobile | Desktop |
|---|---|---|
| Move | Drag anywhere below the top bar (floating joystick) | WASD / arrow keys |
| Shoot | Automatic (nearest enemy in range) | Automatic |
| Gather | Walk next to a tree, rock or bush | Same |
| Upgrades | UPGRADE button | U |
| Pause | II button (also auto-pauses when the app is hidden) | P / Esc |
| Start / restart | PLAY / RESTART | Enter / Space |

## Install as an app

The browser only allows installing a PWA from **HTTPS** (or `localhost`). So to install it on a phone you have to deploy the `dist/` folder to a free static host, for example GitHub Pages, Netlify or Cloudflare Pages. Over plain `http://192.168.x.x`, the game is playable but can't be installed or run offline.

- **Android (Chrome):** tap the in-game INSTALL button, or use the menu → "Install app".
- **iPhone (Safari):** tap Share → "Add to Home Screen". The in-game INSTALL button shows these steps.

Once it has been opened online one time, the game works fully offline.

## Project layout

```
index.html              PWA meta tags, manifest link
public/manifest.webmanifest
public/icons/           generated by scripts/gen-icons.mjs (from the game's pixel art)
scripts/gen-icons.mjs   pure-Node PNG icon generator (runs before every build)
vite.config.js          build + plugin that writes dist/sw.js with the precache list
src/main.js             Phaser config (360x640 portrait, FIT scaling)
src/pwa.js              service-worker registration, install prompt
src/config.js           world size, balance constants
src/logic/              pure game rules (unit-tested): difficulty, upgrades, storage
src/gfx/sprites.js      all pixel art, as character maps rasterised at boot
src/audio/sfx.js        synthesised Web Audio sound effects
src/ui/widgets.js       pixel buttons, panels, virtual joystick
src/scenes/             Boot, Menu, Game, UI (HUD/modals), GameOver
tests/logic.test.js
```

All graphics and sounds are original and generated by code. There are no external assets, paid services or backend. The high score and the mute setting are saved in `localStorage`.
